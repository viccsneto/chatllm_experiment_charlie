## The Problem
A versão atual do ChatLLM é um chat único e sem memória de sessões. Cada conversa acontece em uma janela só, e quando você recarrega a página, o histórico some.

## Steps
- [ ] Criar uma gerência de sessões
- [ ] Input do histórico de mensagem para cada chat
- [ ] Criar um menu lateral com os chats
- [ ] Cada chat ao chamar o llm para responder deve enviar o histórico de mensagens
- [ ] Capturar o assunto principal para colocar como título do chat 

## Success Looks Like
- [ ] Barra lateral com chats divididos do usuário
- [ ] Assunto corretamente capturado
- [ ] Histórico de mensagens salvo

## Notes
- [ ] Título deve ser gerado pelo LLM após a primeira mensagem do chat com mais de 10 tokens
